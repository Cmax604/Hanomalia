Guide de l’administrationRetour à l’administration

Modifier le site sans toucher au code.

L’administration agit uniquement sur la V2 : Cmax604/Hanomalia. Elle ne peut pas modifier le site officiel Hanomalia_Band.

1. Préparer un brouillon

Ouvre l’administration puis « Ouvrir mon brouillon ». Choisis Textes & images, Merch ou Galerie. Les modifications s’enregistrent sur cet appareil ; elles ne sont pas encore publiques. Utilise « Prévisualiser » pour regarder le résultat.

Le stockage du navigateur peut être effacé. Exporte régulièrement une sauvegarde : elle contient ton brouillon et ses nouvelles images.

2. Créer ta clé de connexion GitHub

  1. Connecte-toi à GitHub avec ton compte Cmax604, puis ouvre la création d’un fine-grained personal access token.
  2. Donne-lui un nom, par exemple Administration Hanomalia, et choisis une date d’expiration.
  3. Dans Resource owner, choisis Cmax604. Dans Repository access, choisis Only select repositories, puis uniquement Hanomalia.
  4. Dans Repository permissions, règle Contents sur Read and write. L’accès Metadata en lecture est automatique. Aucun accès aux workflows, paramètres du dépôt ou autres dépôts n’est nécessaire.
  5. Crée la clé et copie-la. GitHub ne l’affichera qu’une fois. Conserve-la dans ton gestionnaire de mots de passe.
  6. Colle-la dans le champ « Clé d’accès » de l’administration, puis clique sur « Se connecter ».

Ne colle jamais cette clé dans un texte du site, dans un fichier du dépôt ou dans une conversation. L’administration l’envoie uniquement à api.github.com. Elle n’est gardée qu’en mémoire et disparaît à la fermeture ou à la déconnexion.

La page de connexion est publique, comme le site ; les modifications du dépôt sont protégées par les permissions de ton compte GitHub. Il n’y a pas de mot de passe caché dans le site ni de serveur de connexion supplémentaire.

3. Publier

  1. Relis les changements dans l’aperçu.
  2. Clique sur Publier sur la V2, puis confirme.
  3. Attends le message de fin de publication, puis actualise le site.

Les photos et le contenu sont enregistrés ensemble dans un commit GitHub. Si quelqu’un a modifié les contenus depuis l’ouverture de ton brouillon, la publication s’arrête pour éviter d’écraser son travail. Exporte ton brouillon avant de recharger la version GitHub.

Photos et albums

Ajoute plusieurs photos à un événement, puis utilise les flèches pour leur ordre. Renseigne les légendes et crédits. Les photos de galerie gardent leurs couleurs ; les portraits de membres gardent le filtre N&B du site. Les images ajoutées sont allégées automatiquement en WebP. Les fichiers RAW doivent d’abord être convertis en JPG ou WebP.

Merch

Modifie le nom, le prix, les tailles et la photo de chaque article. Le lien de commande est facultatif : il peut pointer vers une boutique ou une page de contact. L’administration ne traite aucun paiement. Décoche « Afficher cet article » pour le retirer de la présentation ; décoche « Article disponible » pour le signaler indisponible.

Retrouver une ancienne version

Chaque publication reste dans l’historique GitHub. Une suppression de photo dans un album enlève sa présentation, sans effacer les fichiers d’origine du dépôt. Pour revenir à un brouillon exporté, utilise « Importer une sauvegarde ».

Pour le site officiel

La mise en ligne officielle reste une étape distincte. Valide d’abord la V2 avant de demander son transfert vers Hanomalia_Band.
